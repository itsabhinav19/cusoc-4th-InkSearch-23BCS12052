# InkSearch - Project Understanding

## Objective

Develop a scalable semantic search infrastructure capable of serving millions of users using vector embeddings and AI-native search.

## Functional Requirements

- Document Upload
- Semantic Search
- Authentication
- Recommendation
- Search Analytics

## Non Functional Requirements

- Scalability
- Security
- Observability
- Docker Support
- Kubernetes Deployment

## Proposed Tech Stack

Frontend:
- React
- TypeScript

Backend:
- Python FastAPI

Database:
- PostgreSQL

Vector Database:
- pgvector

Cache:
- Redis

Containerization:
- Docker

Deployment:
- Kubernetes
