# Semantic Search 
It is a way in which instead of searching a word literally, semantic search uses AI  techniques like natural language processing and machine learning to interpret context, synonyms, and related concepts to understand the meaning,

# Embeddings
It is a numerical vector that represents meaning, so an AI model can compare items by similarity instead of exact wording.

# Vector Database
A vector database is a specialized database that stores, indexes, and searches embeddings—numerical vectors that represent the meaning of data such as text, images, or audio.
Instead of looking for exact matches like a traditional database, it finds items that are close in vector space, which usually means they are semantically similar. 

# FastAPI
It is a modern Python web framework for building APIs, designed to be fast to code with and fast at runtime.
It uses Python type hints to validate request data, serialize responses, and help generate cleaner code. It also automatically creates interactive API documentation through OpenAPI/Swagger.
